## `01 // ABOUT`

**Logic Lab** is my programming fundamentals laboratory.

This repository documents my progress while learning programming logic through practical exercises written in **Portugol** and **Python**.

The objective is not only to make the code work.

The objective is to understand:

```text
INPUT → LOGIC → PROCESSING → OUTPUT
```
